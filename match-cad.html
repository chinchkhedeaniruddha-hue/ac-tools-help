Match CAD

Purpose: Copy CAD layer overrides (visibility, colour, line weight, halftone, line pattern, etc.) from one source view template to multiple target templates — in one operation.

When to Use

Use this when you already have a "master" view template with correct CAD layer settings and need to propagate the same settings to other templates without manual Visibility/Graphics edits.

Prerequisites

  • At least two view templates in the project.
  • At least one CAD link or CAD import must exist in the project. If none is present, the tool shows a 3‑step instructional popup instead of the main window.

What to Do If No CAD is Found

The tool shows an informational dialog:

  1. Link the CAD file — Insert → Link CAD.
  2. Set the CAD overrides in one view template — Visibility/Graphics → Imported Categories → set layer colours, line weights, etc.
  3. Re‑run this tool — it will now detect the CAD and open the transfer window.

Step-by-Step

  1. Click Match CAD on the AC Tools ribbon.
  2. Source View Template (left) — select the template that already has the correct CAD settings.
  3. Target View Templates (right) — click Select All or Ctrl+click individual targets.
  4. CAD Imports & Layers (bottom tree) — expand a CAD import and tick the layers you want to copy. Use the checkboxes at the import level to include all its layers. Use Inverse to flip the selection, or type in the Search box to filter.
  5. Click Copy CAD Layer Overrides.
  6. Review the summary dialog after the transfer completes.

Expected Output

  • For every (target template × selected layer) pair, the target's category override is replaced by the source template's override.
  • A summary reports Copied N overrides to M target templates.
  • Any per‑layer failure is logged and reported without aborting the whole run.

Troubleshooting

  • "At least 2 view templates are required" — create a second template in the View Templates dialog.
  • CAD layers not showing in the tree — the CAD link/import may be corrupt or Revit hasn't loaded its categories yet; reload the CAD and re‑run.
  • Some layers skipped — some imported categories are read‑only in certain templates. Check the Output window for details.

Precautions

This tool overwrites existing CAD layer overrides on the target templates. Duplicate target templates first if you want to preserve old settings.
