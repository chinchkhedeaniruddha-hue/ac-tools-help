Crop Offset

Purpose: Configure annotation crop offsets on one or many views, and bulk export/import those values through Excel.

When to Use

Use this when annotation (tags, dimensions, text) is being clipped by the view crop, or when you need to standardize the annotation‑to‑crop distance across many sheets before printing or issuing drawings.

Prerequisites

  • Views must support annotation crop (Floor Plans, Ceiling Plans, Elevations, Sections — not 3D, Legends, Schedules, Sheets).
  • For Export/Import, Microsoft Excel must be installed on the machine (uses Excel Interop).

The Dialog

The Crop Offset window offers three actions:

  • Set Annotation Offsets — apply Left / Right / Top / Bottom values (in mm) to the currently selected views (or the active view if nothing is selected).
  • Export ALL Views to Excel — write every annotation‑capable view in the project to an .xlsx file.
  • Import ALL Views from Excel — read the edited .xlsx back and apply offsets to every matching view.

Step-by-Step — Apply to Selected Views

  1. Select one or more views in the Project Browser (Ctrl+click for multiple).
  2. Click Crop Offset on the AC Tools ribbon.
  3. Set the four offset values (default 3 mm). Positive values only.
  4. Click Set Annotation Offsets.
  5. Click Apply. A confirmation dialog reports how many views were updated.

Step-by-Step — Bulk Export / Import

  1. Click Export ALL Views to Excel → choose a save location.
  2. The workbook contains columns: View ID, View Name, View Type, Left (mm), Right (mm), Top (mm), Bottom (mm), plus a summary sheet.
  3. Edit the offset values in Excel (do not rename columns or delete rows), save, and close Excel.
  4. Click Import ALL Views from Excel and select the same file.
  5. Confirm the warning dialog. The import runs in a single transaction.
  6. A results dialog shows succeeded / skipped / failed views.

Expected Output

  • Crop Box and Annotation Crop are enabled on each affected view.
  • Offset values are applied in feet internally (mm × 0.00328084).
  • Excel export produces one row per view, colour‑coded and auto‑fitted.

Troubleshooting

  • "Does not support annotation crop" — the view is a 3D, Legend, Schedule, or Sheet. Excluded by design.
  • Import silently skips a view — its ID no longer exists (view deleted). Match by Name will be attempted as a fallback.
  • Excel Interop errors — ensure Excel is installed and not blocked by a pending "recover document" dialog.

Precautions

Import overwrites every listed view's annotation crop values. Save a backup of the project before running Import. Excel must be closed before import, otherwise the file may lock.
