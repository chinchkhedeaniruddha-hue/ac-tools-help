Sheet Align

Purpose: Align viewports across multiple sheets to match the layout of a chosen "main" template sheet.

When to Use

Use this when you have a batch of sheets that should all look identical to a reference sheet (same viewport position, same label placement), but were placed at slightly different positions.

Prerequisites

  • At least two sheets in the project (one to serve as the main template, at least one to align).
  • Sheets should already contain viewports — Sheet Align does not add viewports.

Step-by-Step

  1. Click Sheet Align on the AC Tools ribbon.
  2. In the sheet list, click the radio button next to the sheet you want to use as the main template.
  3. Ctrl+click to select one or more other sheets to align.
  4. Align viewport labels (on by default) — also copies viewport label offsets from the main sheet.
  5. Match by view name (on by default) — matches viewports on target sheets to the same view name on the main sheet. Turn off to fall back to first‑viewport matching.
  6. Click ALIGN VIEWPORTS.
  7. A completion dialog reports how many viewports were aligned across how many sheets.

Expected Output

  • Each target sheet's viewports move so their centre point matches the corresponding viewport on the main sheet.
  • If Align labels is enabled, label offsets are also matched.
  • Every target sheet is processed in its own transaction — one failure does not block others.

Troubleshooting

  • "Please select a main sheet" — no radio button was selected. Click the radio next to any sheet.
  • "Please select at least one other sheet" — Ctrl+click target sheets in the list.
  • Viewport not aligned — the target sheet may lack a viewport with the same view name. Disable Match by view name and re‑run.

Precautions

This modifies viewport positions on the target sheets. Save the project first if you want a clean rollback point — multi‑sheet transactions cannot all be undone with a single Ctrl+Z.
