Sheet Tool (View Duplicator)

Purpose: Duplicates selected views across multiple scope boxes and optionally creates sheets with viewports already placed.

When to Use

Use this tool when you need to produce the same plan, section, elevation, or 3D view multiple times — once per building area (scope box) — with consistent naming and optional sheets.

Prerequisites

  • The project must contain at least one Scope Box. If none exist, the tool shows a warning and stops.
  • At least one printable view (Floor Plan, Ceiling Plan, Elevation, Section, or 3D) must exist.
  • If creating sheets: at least one Title Block family must be loaded and activated.

Step-by-Step

  1. Click Sheet Tool on the AC Tools ribbon (View Management panel).
  2. Select views: choose a view from the dropdown, click Add View. Repeat for every view you want to duplicate.
  3. For each view, enter a Starting Sheet Number in the table (only required if creating sheets).
  4. Select scope boxes: pick from the left list, click ↓ to add. Use Add All to add every scope box.
  5. Naming options (optional): set Prefix, Suffix, Find, and Replace. Final view name = {Prefix}{ProcessedViewName}{Suffix} - {ScopeBoxName}.
  6. Title Block (only if creating sheets): choose from the dropdown, then click Set Viewport Position and drag a rectangle on the title‑block preview to define where viewports land.
  7. Tick Create sheets for new views if you want sheets generated automatically.
  8. Click Create Views. A confirmation dialog appears — review the totals and click Yes.

Expected Output

  • N dependent views, where N = (selected views) × (selected scope boxes).
  • If Create Sheets was on: N new sheets, each with the corresponding view placed at the configured viewport position.
  • Sheet numbers increment from the entered starting number per view (e.g. A101, A102, A103…).

Warnings & Common Errors

  • "Kindly create a scope box first" — no scope boxes in project. Create one from Architecture/Structure tab → Scope Box.
  • "Please enter a starting sheet number" — sheet creation is enabled but a row has no number.
  • "Failed to create N view(s)" — some views can't be duplicated (templates, browsers). Check the summary dialog.
  • Duplicate names are auto-resolved with a (1), (2) suffix.

Precautions

This tool modifies the model (creates views and sheets). Close any unsaved drawings first. To roll back, use Revit's Undo (Ctrl+Z) — everything happens in a single transaction.
